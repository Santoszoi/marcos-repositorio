# Marcos Portfolio

Exportação em formato estático do portfólio Marcos.dev.

## Como abrir
Abra `index.html` diretamente no navegador.

## Como publicar
A pasta pode ser enviada para serviços de hospedagem estática, como Netlify, GitHub Pages ou qualquer servidor web.

## Antes de publicar
- Troque os links de GitHub, LinkedIn e e-mail no final de `index.html`.
- Conecte o formulário de contato a um backend ou serviço de formulários.
- Substitua projetos demonstrativos por projetos reais quando disponíveis.

Arquivos principais:
- index.html
- styles.css
- script.js
